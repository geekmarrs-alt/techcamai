Get Started
Everything included

Built for operators.
Not admins.

Every feature in TECHCAMAI is designed around one question: what does a security operator actually need right now?

🔔

Rule-based Alerts

Create detection rules per camera with configurable labels (motion, person, vehicle), confidence thresholds, and cooldown windows to eliminate noise.

🎬

RTSP Clip Capture

Every alert triggers an ffmpeg RTSP clip capture. Clips are stored locally, tracked (pending/ready/failed), and playable in-browser without any external tools.

📡

LAN Camera Discovery

Built-in network scanner finds IP cameras on your LAN automatically. Test credentials, verify snapshot URLs, and add cameras to inventory — all from the UI.

🖥

Premium Dashboard

3-column operator console: live camera stage, alert inbox rail, and clip playback queue. Smart prioritisation ensures unacked alerts always surface first.

⚡

Live Snapshot Wall

Full-screen camera grid with configurable refresh rates (2–10s). Monitor all cameras simultaneously with instant access to individual feeds.

🥧

Raspberry Pi Native

Multi-arch Docker images (amd64 + arm64) built for Pi. Host networking gives the worker direct LAN access to cameras. Watchtower auto-updates silently.

🔒

Camera Protocol Support

Native Hikvision ISAPI support. RTSP and HTTP snapshot fallbacks for all major OEMs. Basic and Digest authentication, plus embedded credentials in RTSP URLs.

📊

Event Timeline

Chronological incident flow across all cameras and rules. Filter, acknowledge, and review clips from a single timeline view. Built for shift handovers.

💡

Zero Cloud Dependency

Every byte stays on-site. No camera footage, alert metadata, or clip data ever leaves your LAN. SQLite database, local storage, fully self-contained.
