Edge deployment

One command.
Runs on a Pi.

Install TECHCAMAI on a Raspberry Pi in under two minutes. Docker Compose manages the API and worker containers. Watchtower pulls stable image updates automatically — no SSH required after day one.

  • Raspberry Pi OS — Lite or Desktop, amd64 + arm64
  • Host-network mode for direct LAN camera access
  • Auto-updates via Watchtower on a daily schedule
  • SQLite — no database server to manage
