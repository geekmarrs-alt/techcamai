Up and running
in two minutes.

One command. Docker handles the rest. Works on Raspberry Pi, Ubuntu, and any amd64/arm64 Linux host.

ℹ️
Prerequisites
Docker + Docker Compose must be installed. On a fresh Raspberry Pi, the installer handles this automatically. On existing hosts, install Docker Engine first.
🥧

Raspberry Pi

Recommended. Installs Docker if missing, configures host networking, and starts the stack. Point a browser at http://<pi-ip>:8000 when done.

# Replace HOST:PORT with your file server or use the hosted installer
curl -fsSL techcamai.com/install.sh | sudo bash \
  --camera-urls "rtsp://user:pass@192.168.1.10/stream"
Copy Pi install command
🐳

Docker Compose

For any x86-64 or arm64 Linux host. Clone the repo, copy .env.example to .env, and bring the stack up.

git clone https://github.com/geekmarrs-alt/techcamai
cd techcamai
cp .env.example .env && nano .env
docker compose up -d
