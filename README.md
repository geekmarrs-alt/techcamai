# TECHCAMAI: Windows AI CCTV Monitoring System (Camia Edition)

TECHCAMAI is a professional-grade, edge-first AI CCTV monitoring system designed exclusively for Windows. It features the **Camia** AI assistant, remote OS notifications, and a multi-threaded stable monitoring engine.

## 🚀 Quick Start (Windows Only)

1.  **Download:** [Download TECHCAMAI_Windows_v2.zip](https://github.com/your-repo/archive/main.zip) (replace with your actual link) and extract it.
2.  **Install:** Double-click `windows_install.bat`.
    *   This installs all Python requirements.
    *   Verifies FFmpeg is available.
    *   **Creates a "TechCamAI" shortcut on your Desktop.**
3.  **Launch:** Double-click the **TechCamAI** shortcut on your desktop. The system runs in "Ghost" mode (no background terminal windows).

## 🤖 Meet Camia (The AI Assistant)

Look for the pulsing **Orb** in the top-right corner.
*   **Interactivity:** Click the orb or press `Cmd+K` (Ctrl+K) to toggle the Camia command panel.
*   **Voice Status:** Camia provides natural language reports on site health and incidents.
*   **Jarvis-Style UI:** A retractable, non-intrusive console for history and commands.

## 🌓 Day & Night Modes

Customize your monitoring environment using the **Appearance** toggle in the sidebar. The system remembers your preference for the next session.
